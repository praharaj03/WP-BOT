Setup

1. Copy .env.example to .env and add your OpenAI API key.

2. Run npm install, then npm start.

3. Open this dashboard and scan the QR shown in the terminal using WhatsApp → Linked devices.

This uses WhatsApp Web automation. Use it only for your own account; unofficial automation may violate WhatsApp rules or cause account restrictions.
